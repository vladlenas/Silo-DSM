Library scan

When torrents are added to or removed from Silo, Plex is asked to scan its libraries. Meant for a Plex library on the folder where the FUSE plugin mounts Silo.

Plex server

Leave the token empty to keep the saved one. To find it: Plex Web → any movie → ⋯ → Get Info → View XML; the token is the X-Plex-Token value at the end of the address.

Libraries

Choose the libraries on the Silo folder. None chosen = all libraries.
