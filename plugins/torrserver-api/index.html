Connect an app

Apps that work with TorrServer (Lampa, Seena and others) see Silo as a TorrServer: torrents chosen in the app are added to Silo and play from Silo.

  1. In the app, open its TorrServer settings.
  2. Enter this address as the TorrServer address.
  3. If you set a login and password below, enter the same in the app.
  4. Pick a torrent in the app: it appears in Silo's library.

Magnet links and hashes can be added; a result with only a link to a .torrent file cannot (yet). Transcoding through TorrServer (GStreamer) is not available: the app plays the file as it is.

Settings

Only needed when Silo has an owner password: playback goes through Silo's own stream address, which then needs that user's player token. Empty fields keep what is saved.
