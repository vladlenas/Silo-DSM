Setup

The same torrent is read through both servers the way a player reads it, each time from a cold start (the torrent is closed first). The rounds alternate who goes first, so neither gets a warmed-up swarm.

Run it from a computer on a cable if you can: on Wi-Fi or a tablet the network to this device can be slower than the torrent and both servers look the same. Close other playback on the NAS and do not open the torrent's card in Silo or TorrServer while the test runs (an open card keeps the torrent awake).
